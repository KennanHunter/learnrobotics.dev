# The CPU

The device you're reading this on right now, is really just a fancy calculator.
You hear that ever so often when we talk about computers but I really want you
to think about what that means. Every pixel, every keyboard input, every website
you visit really just boils down to a bunch of operations done by math. A modern
CPU can run somewhere around 4GHz. That means that every second, a CPU can do
4,000,000,000 operations one after another.

Trying to understand exactly how that math builds up to a website like the one
you're reading, is the kind of question that will lead you through many, many
interesting fields of computer science and engineering. This course will look at
one of them, with the end goal of preparing you with the fundamentals to write
code for the FIRST Tech Challenge and FIRST Robotics Competition.

# CPU Microcode

Every CPU has what's called a instruction set. A instruction set is the lowest level
interface between a CPU and user code. Instruction sets describe how a CPU does basic
math, branches between different parts of the code, and reads and writes data for future
operations in the form of memory.
